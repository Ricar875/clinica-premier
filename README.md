24 de mai.
Para enviar arquivos ao GitHub, siga estes passos:

1. Instalar o Git
Baixe em git-scm.com se ainda não tiver.

2. Configurar o Git (primeira vez)
bash
git config --global user.name "Seu Nome"
git config --global user.email "seu@email.com"
3. Criar repositório no GitHub
Acesse github.com → New repository
Dê um nome e clique em Create repository
4. Na pasta dos seus arquivos (terminal/cmd)
bash
# Iniciar o repositório local
git init

# Adicionar os arquivos
git add .

# Salvar com uma mensagem
git commit -m "primeiro commit"

# Conectar ao GitHub (copie a URL do seu repositório)
git remote add origin https://github.com/seu-usuario/seu-repositorio.git

# Enviar para o GitHub
git push -u origin main
Atualizar depois (quando fizer mudanças)
bash
git add .
git commit -m "descrição da mudança"
git push
Dica: Se for a primeira vez fazendo push, o GitHub vai pedir seu usuário e senha (ou token de acesso).
